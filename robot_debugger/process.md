## 2025-05-20: QStackedWidget 오류 수정

### 문제
QStackedWidget::setCurrentWidget에서 다음과 같은 오류가 발생했습니다:
```
[robot_debugger_ui_node-1] QStackedWidget::setCurrentWidget: widget 0x0 not contained in stack
```

### 원인
central_widget_(QStackedWidget)에 등록되지 않았거나 null인 위젯을 현재 위젯으로 설정하려고 시도했기 때문입니다.

### 수정 사항
1. 각 탭 전환 버튼의 클릭 이벤트 핸들러에서 위젯이 null이 아니거나 인덱스가 유효한 경우에만 setCurrentWidget 또는 setCurrentIndex를 호출하도록 수정했습니다.
2. 초기 위젯 선택 코드도 위젯이 존재하는 경우에만 설정하도록 변경했습니다.

```cpp
// 변경 전:
central_widget_->setCurrentWidget(dashboard_);

// 변경 후:
if (dashboard_) {
    central_widget_->setCurrentWidget(dashboard_);
} else {
    qWarning() << "대시보드 위젯이 null입니다. 탭 전환 불가.";
}
```

이와 같이 모든 탭 전환 코드를 수정하여 null 위젯을 참조하는 문제를 해결했습니다.
